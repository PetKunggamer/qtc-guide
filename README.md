# คู่มือระบบดูแลงานส่งของ QTC

สวัสดีครับ 👋 นี่คือคู่มือการใช้งาน **ระบบที่ช่วยดูแลงานส่งของของบริษัท** เขียนไว้แบบเข้าใจง่าย ไม่ต้องมีความรู้คอมพิวเตอร์มาก่อนก็อ่านตามได้เลยครับ

## ระบบนี้คืออะไร (พูดง่ายๆ)

ระบบนี้มี 2 ส่วนหลักๆ:

1. **หน้าจอสำหรับดูแลงานส่ง** (สำหรับพนักงานออฟฟิศ) — ใช้ดูว่ามีออเดอร์อะไรบ้าง ใครขับรถไปส่งอยู่ที่ไหน ของถึงลูกค้าหรือยัง มีรูปถ่ายยืนยันการส่งของหรือเปล่า
2. **หน้าจอสำหรับคนขับรถ** (เปิดจากมือถือ) — คนขับใช้บอกว่ากำลังจะไปส่งของชิ้นไหน แจ้งปัญหาระหว่างทาง และถ่ายรูปยืนยันตอนส่งของเสร็จ

ทั้งสองส่วนเชื่อมกันอัตโนมัติ พอคนขับกดอะไรในมือถือ ฝั่งออฟฟิศจะเห็นทันที ไม่ต้องโทรถามกันไปมา
